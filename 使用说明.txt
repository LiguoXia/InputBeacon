键盘状态 InputBeacon 1.4.3 · 透明悬浮 / 任务栏状态 / 光标跟随

一、直接使用
双击“键盘状态.exe”，首次使用会出现悬浮窗；以后会记住上次选择的显示方式。
这是单文件程序，无需安装。面向 Windows 10 / 11，使用系统的 .NET Framework 4.8。
文件夹里的 exe 可以单独复制到其他位置使用。

二、显示含义
左侧“中”：当前 Windows 输入法为中文模式。
左侧“英”：当前 Windows 输入法为英文模式。
左侧“?”：当前窗口没有提供可读取的输入法状态。
右侧“A”或“a”：按常规英文键盘计算的字母大写或小写。
字母下方的小圆点：Caps Lock 已开启。
右上角小箭头“↑”：正在按住 Shift，字母大小写临时反转。
中 / 英下方的小圆点：当前为全角输入，终端命令需要留意。
例如 Caps 开 + Shift 按住时，字母显示小写。
鼠标停在文字上，可查看详细的中英文、大小写和 Caps / Shift 状态。

悬浮窗使用完全透明背景，没有底板、边框或黑色背景。
标准尺寸为 84×36（逻辑像素），在原有大小选项和屏幕缩放基础上调整。
使用逐像素透明、4 倍分辨率渲染和高质量缩小处理文字边缘。

三、光标跟随气泡
右键文字或通知区域图标 → 跟随显示设置…。
勾选“在输入光标右上方显示状态”，选择显示时长，点击“应用”。
也可在菜单中直接勾选“光标跟随显示”快速开关。

“切换后 N 秒消失”：支持 1～60 秒，默认 3 秒。
中英文变化连续稳定至少 200 毫秒后出现；实际 A/a 变化在下一次轮询时提示。
进入另一个输入框时，即使中英文与大小写没变，也显示一次当前状态。
例如从浏览器搜索框切到微信输入框，或从其他输入框切回来，都会重新计时。
跨应用或原生输入控件切换：首次读到有效光标及输入状态就显示，不额外等待 200 毫秒。
同一窗口内的虚拟输入框：再确认一次轮询，通常约 100 毫秒，以过滤单次控件标识波动。
倒计时从确认显示时开始；实际响应仍取决于轮询时机及目标应用的光标接口。
读取失败及恢复、全角标记波动、同一输入框内光标暂时消失不会重复触发。
Caps / Shift 组合改变但 A/a 没变时不额外提示。此修复针对微信 + 微软拼音报告的误弹路径。
移动光标不会延长倒计时，确认再次切换状态后重新计时；显示期间也会随光标移动。
“一直显示”：只要能读取输入光标，就持续显示，并随输入、换行和光标移动。
启动或重新启用跟随后，在第一个有效输入框中也显示一次。
同一输入框内继续打字和移动光标不会延长倒计时。
部分自绘输入框没有独立控件标识，同一窗口内的切换可能无法识别。

跟随的是文本插入光标，不是鼠标指针。
提示默认出现在光标右上方，接近屏幕边缘时自动移到左侧或下方。
跟随提示为 72×34 逻辑像素的浅色半透明圆角气泡，尖角贴近光标。始终鼠标穿透，不抢键盘焦点。
与悬浮窗和任务栏共用文字颜色，与悬浮窗共用大小及文字不透明度。
三种显示方式可任意组合；只想跟随时，关闭悬浮窗和任务栏状态即可。
菜单、设置窗口打开时，或当前应用没有提供可靠光标位置时，跟随提示会隐藏。
Canvas 自绘网页终端和部分 SSH 客户端可能不提供光标位置，需要实机验证。

IDEA / Java 编辑区：
先打开 IDEA，再右键图标 → IDEA / Java 光标支持… → 启用 Java 光标支持。
保存工作并完全退出、重新打开 IDEA。若仍无提示，在 IDEA 外观设置中开启 Support screen readers。
按钮使用 Java 自带的 jabswitch 工具启用当前用户的桥接配置，不自动重启 IDEA。
1.4 补充资源管理器现代输入框的 UIA TextPattern2 光标接口；1.4.1 增加空范围的字符几何回退。
跟随功能启用时，后台定位在气泡隐藏期间保持连接，改善短倒计时的首次定位。
Java 独立输入框已通过 6 阶段集成检查；新版在微信 + 微软拼音、IDEA 编辑区和资源管理器中的完整实测仍待完成。

四、其他操作
右键“文字颜色…”：选择预设色、打开系统调色盘，或输入 HEX 色值。
HEX 支持 #0071E3、0071E3、#FFF 等写法；颜色预览同时提供浅色和深色背景。
点击“应用”后生效并保存；“取消”不修改原设置；“恢复默认配色”后点“应用”恢复蓝色 / 橙色。
自定义颜色同时应用到悬浮窗、任务栏状态和光标跟随；固定悬浮窗背景完全透明。

右键“任务栏显示状态（中/英 · A/a）”：开关任务栏右侧的两个状态图标。
右键“显示悬浮窗”：单独开关悬浮窗。各显示方式的开关互相独立并会保存。
可以只用悬浮窗、只用任务栏状态、或两者同时显示。
首次开启任务栏状态时，Windows 可能把图标放入“^”隐藏图标菜单，拖出来即可常显。
两个图标的次序可在任务栏中拖动调整。程序使用系统通知区域，不会覆盖任务栏按钮。
三种状态显示都关闭后，仍保留一个软件图标，方便再次进入设置或退出。
首次默认显示悬浮窗，关闭任务栏状态和光标跟随；升级会保留已有偏好。

按住文字左键拖动：改变位置，退出后自动记住。
右键文字或任务栏通知区域图标：调整大小、文字不透明度、鼠标穿透、开机启动或退出。
完全透明的空白处会自然透过鼠标点击，请在文字处拖动或右键。
双击任一通知区域图标：隐藏 / 显示悬浮窗。图标可能在任务栏的“^”里。
鼠标穿透：鼠标点击会交给后面的窗口，从通知区域右键菜单取消。
再次双击 exe：找回已有悬浮窗并关闭鼠标穿透，不会重复运行多个实例。
“重置位置”：把悬浮窗放回鼠标所在屏幕的右上角。
开机启动默认关闭，需要时在右键菜单中开启；移动 exe 后请关闭再开启此项。
没有全局快捷键，不会占用终端快捷键。

五、浏览器终端 / SSH 客户端
先点击浏览器里的终端输入区域或 SSH 客户端，再切换中英文、Caps Lock。
程序约每 100 毫秒读取一次当前获得键盘焦点窗口的状态。
支持情况取决于输入法和客户端是否提供 Windows IME 状态。
如果持续显示“?”或定时气泡仍无故出现，可以右键选择“复制状态诊断”，提供给开发者排查。
诊断包含显示秒数、触发次数和原因，不包含输入文本或聊天内容。
Input field focused 表示进入输入框引发的正常提示。
若客户端以管理员权限运行，普通权限的指示器可能无法读取其输入法状态；
确有需要时，可以让两者使用相同权限运行。

显示的是本机 Windows 状态，不能读取 Linux 远端、网页自建输入法、
虚拟机内部或远程桌面内部独立维护的输入模式；远端键盘重映射也可能影响最终字符。
部分第三方输入法不提供或错误提供 IME 状态，需要在实际客户端中验证。
安全桌面、独占全屏环境不保证显示悬浮窗。

六、设置和隐私
设置保存在 %LOCALAPPDATA%\InputBeacon\settings.ini。
程序不联网，不记录输入文本，不修改中英文或大小写状态。
只有用户手动开启“开机启动”时，才写入当前用户的启动项。
卸载：若开启了开机启动，先在右键菜单关闭；退出程序后删除 exe 即可。
需要清除偏好时，可另行删除上面的设置文件夹。

七、开发者
完整项目的源码在 src 文件夹，build.ps1 可使用系统自带的 C# 编译器构建。
PowerShell 执行：.\build.ps1 -Test
自测结果及渲染图在 test-output。
