# 真机验收清单

下面是需在真实 Mac 用户会话手动执行的检查，不代表已经完成。CI 不提供已授权的交互桌面。

- [ ] Intel / Apple Silicon 各安装一次，核对系统版本与下载 SHA-256。
- [ ] 将 DMG 程序移入 Applications，确认首次打开、菜单入口、重复启动与退出。
- [ ] 中英文输入源、其他语言、Caps Lock、Shift、Caps+Shift 的显示；单独记录第三方输入法内部英文模式的限制。
- [ ] 搜狗保持同一输入源，按 Shift 中文 / 英文来回切换；固定窗、菜单栏、跟随提示都同步变化。
- [ ] 搜狗在“自动英文”应用与普通中文应用之间切换，不能沿用前一应用的状态。
- [ ] 搜狗退出 / 重启、回复丢失时显示未知；恢复有效查询后更新；确认诊断记录状态来源与查询结果。
- [ ] 支持查询协议的鼠须管切换 ASCII 模式；无协议的旧版本应显示未知而非错误地保持中文。
- [ ] 拖动、穿透、恢复位置，关闭所有显示后仍能从菜单恢复。
- [ ] 缩放、颜色、非法 HEX、透明度，重启后偏好保留。
- [ ] 未授权时菜单栏 / 固定悬浮窗正常；授权、撤销后跟随正确开启 / 隐藏。
- [ ] TextEdit 普通文本中首次进入、换行、移动光标、切换输入框；倒计时不因打字续时。
- [ ] Chrome / Safari 表单、Terminal / iTerm2、微信、IDEA 分别记录实际兼容性。
- [ ] 不支持的输入区域、密码框、选中文本不错误跟随，操作菜单时不出现气泡。
- [ ] 多屏左右 / 上下布局、切换 Spaces、屏幕断开、全屏应用及屏幕边缘避让。
- [ ] 登录启动启用 / 关闭、系统设置需要批准的状态及注销重新登录。
- [ ] 诊断无文本内容，长时间运行资源占用稳定。
