# InputBeacon macOS 1.1.0

第三方输入法兼容更新，重点修复搜狗内部切换中英文后提示不变化的问题。

- 支持 macOS 13+，同一安装包原生支持 Intel 和 Apple Silicon。
- 搜狗：读取输入法自身的中英文状态；支持同一输入源下中文、英文、自动英文和 Caps 英文。无需安装搜狗切换助手。
- 鼠须管：通过其 ASCII 模式查询协议获取状态；安装版本需实现该接口。
- 防止切换应用后沿用旧状态，增加超时、过期回复与异常数据处理。不根据 Shift 次数猜测输入状态。
- 改进输入源元数据缺失时的分类，诊断中增加状态来源、查询结果与回复次数；提供 `--diagnose` 10 秒动态诊断。
- 保留透明悬浮窗、菜单栏、光标跟随、大小写与所有外观设置；中英文内部切换同样触发跟随提示。

## 下载

一般用户下载 `InputBeacon-macOS-1.1.0-universal.dmg`，拖入 Applications 后运行；ZIP 为相同程序的压缩版。`SHA256SUMS.txt` 用于校验。

## 首次使用及已知边界

- 临时签名，**没有 Apple Developer ID 签名或公证**。首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。
- 光标跟随需“辅助功能”权限；固定悬浮窗 / 菜单栏可独立使用。
- 搜狗 / 鼠须管通过本地查询识别内部中英文；不支持查询的旧版本或回复超时会显示 `?`。其他输入法仍按系统输入源语言显示，不代表所有第三方输入法均已适配。
- 仅在应用提供可靠插入光标位置时跟随；不读取输入文本，不使用鼠标位置猜测。不保证兼容所有终端、浏览器或 IDEA 版本。
- 双芯片自动化覆盖 36 项核心及通知接收器测试、通用包构建和界面启动；搜狗安装包检查只验证真实进程的状态查询回复。托管桌面无法激活新输入源，真实 Shift 切换、微信 / IDEA 场景仍待真机验收。
- 鼠须管协议已适配，尚未完成真实输入法会话测试；其他搜狗版本、macOS 13 真机和登录启动也需分别验证。

详细说明：[macOS 使用说明](https://github.com/LiguoXia/InputBeacon/blob/macos-v1.1.0/macos/README.md)。Windows 版本及其最新下载入口保持独立。
